# Site Thermcam (GitHub Pages)

## Publicar pela primeira vez
1. Crie um repositório no GitHub (ex.: `thermcam`) e envie todos estes arquivos para a branch `main`.
2. Em **Settings → Pages → Source**, escolha **GitHub Actions**.
3. Edite `site.config.json` e troque `url` pelo endereço real (ex.: `https://SEU-USUARIO.github.io/thermcam` ou seu domínio).
4. Aguarde a aba **Actions** ficar verde. O site abre em `url`.

## Publicar matérias (jeito simples)
Abra `SUA-URL/admin/`, preencha a aba **Conexão** uma vez (usuário, repositório e token com permissão *Contents: Read and write*) e use **Nova matéria**.

## Fotos
- Projetos: coloque fotos em `assets/img/projetos/` (jpg/png/webp) — aparecem sozinhas na galeria.

## Google
Depois de publicar: Search Console → adicionar propriedade → enviar `SUA-URL/sitemap.xml`.
